# Upstream research

## PS5 managed-USB formatting (2026-09-26)

**VERIFIED HARDWARE / DECRYPTED 4.50 LIBRARIES:** the first user-confirmed `sceShellCoreUtilFormatExternalHdd("/dev/da1")` request returned `0x80020001` while `/dev/da1p1` was still mounted as exFAT at `/mnt/usb0`; the drive contents remained intact. ShellCore accepted the request, so its caller capability-word-0 bit-62 gate was satisfied. In decrypted `libSceFsInternalForVsh` (SHA-256 `7782656a88c7da1ed5a8cc4d2169e405953a963828d781e5ca42c5f8b659a660`), export `h4i3gkTA9EU` (`sceFsExternalStorageInitialize`, VA `0x186d0`) creates a GEOM CRYPT provider before raw writes. Its `/dev/geom.ctl` ioctl failure converts `errno == EPERM` to `0x80020001` and propagates it unchanged. ShellCore's separate native preparation paths unmount before operating on the raw provider. PS5Library now follows that ordering with an exact, non-forced unmount and post-unmount device-identity check. A second destructive hardware attempt remains pending.

### First-run input and connection handling

**VERIFIED source:** in the pinned SDL `src/video/ps5/SDL_ps5keyboard.c`, `PS5_ShowScreenKeyboard` clears the native input buffer and calls `sceImeDialogInit`. On accepted input, `PS5_ImeDialog_PumpEvents` emits UTF-8 text followed by an auto-release Return key. `PS5_IsScreenKeyboardShown` reports RUNNING. Our frontend replaces the selected server field on new text, consumes Return to advance focus, and ignores storefront navigation while the native keyboard is shown. The user now confirms the storefront/server-address keyboard on 4.51, and saved configuration plus server contact establish successful address entry. Cancellation and input edge cases remain **UNKNOWN**.

**VERIFIED documentation/local checks:** libcurl's [URL API](https://curl.se/libcurl/c/libcurl-url.html) parses server origins; [curl_url_get](https://curl.se/libcurl/c/curl_url_get.html) supports `CURLU_NO_DEFAULT_PORT`. [CURLOPT_XFERINFOFUNCTION](https://curl.se/libcurl/c/CURLOPT_XFERINFOFUNCTION.html) with `CURLOPT_NOPROGRESS=0` aborts a request when the callback returns nonzero. The native client uses these existing APIs for origin normalization and cancellation, retaining certificate verification and disabling redirects. Native HTTPS on physical PS5 is still untested.
