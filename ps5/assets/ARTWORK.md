# PS5Library home artwork

`store-home-master.png` was created with the built-in image-generation tool using `store-icon-master.png` as the identity reference. `pic0` and `pic1` intentionally use the same 3840 x 2160 artwork so the home and switcher surfaces keep one visual identity. Their identical DDS files are BC7 textures generated through the existing LibProsperoPKG encoder. The installer includes `icon0.dds` alongside the existing icon. PNG dimensions and DDS magic, dimensions, DXGI format 98 and exact payload size were checked.

These are our app's assets. Their appearance when selecting the home tile still needs a physical console check. No system-wide theme or other title's metadata is replaced.

The PS5 shell controls the transition between `pic0` and `pic1`. No verified package-local field provides home-screen hover video; trailers play inside PS5Library after launch.
