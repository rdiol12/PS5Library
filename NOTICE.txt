PS5 client dependencies
-----------------------
Public PS5 payload SDK v0.43:
https://github.com/ps5-payload-dev/sdk/tree/d9c9519116944a7f1c22d262012c53b80b3520b7

Port build recipes v0.40.2:
https://github.com/ps5-payload-dev/pacbrew-repo/tree/1687e827675c66e1b040751c7f0811222bd3aea0

The console frontend links FFmpeg with GPL features and x264. Matching source
archives, build recipes, and original license files are recorded under
frontend/licenses/. Inter fonts and their SIL Open Font License are under
frontend/ps5/assets/fonts. The CA bundle is embedded from the pinned build image.

Server worker dependencies
--------------------------
The package worker builds from the pinned LibProsperoPKG and UFS2Tool sources
under server/upstream/. Their original licenses and notices remain beside those
sources. JavaScript dependency versions are recorded in server/package-lock.json.

Release boundary
----------------
The repository and release assets do not include games, dumps, package links,
credentials, private signing keys, proprietary publishing tools, or Sony SDK
files. The public Ed25519 update verification key is intentional; its private
signing key is not included.
